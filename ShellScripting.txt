SED editor
===========
strealine editor, it is a non-interactive editor(no need to open or any human interaction not required)
it used for create the line
update the line
delete the line


sed '1i Hello SED' <file-name> -> insert before first line but its temporrary only shown on the screen doesn't impact the actual file.

sed '2d' -> delete 2nd line
sed '/Hello/d' -> delete lines where there is Hello
sed 's/root/ROOT/' -> substitute the first occurence in every line
sed 's/root/ROOT/g' -> substitute all occurences in every line
sed '3c Hello change' -> replace 3rd line
sed '/error/ c NO-ERROR' -> change the line based on pattern
